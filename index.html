Mount WebDAV / NAS as a Windows drive letter without copying files

Short answer: map the remote share to a local drive letter so apps open paths like Z:\... — no bulk copy to the PC.

ScsDrive does this on Windows for WebDAV / NAS / cloud folders.

Is "Map network drive" the same as a real drive letter?

No. Windows' own Map network drive (WebClient service) creates a network drive that lives under Network locations and goes through a redirector; software that insists on a local path will refuse it. A real local volume appears under This PC → Devices and drives with a normal letter and behaves like an internal disk.

Does mounting need administrator rights?

Mounting does not — you mount with your own account in your own session. On the first launch the client sets up the open-source user-mode file-system driver it needs (Dokany, LGPL) by itself: no kernel component, nothing for you to install or configure.

Will the drive survive a reboot, and can my backup service see it?

A mount belongs to the Windows session that created it, which has two practical consequences:

  • Services and scheduled tasks running in Session 0 do not see the drive letter, so a backup agent or script started that way reports a missing path. Run it in an interactive session as the same user who owns the mount.
  • After a reboot the drive letter is not there at boot; the client re-creates the mounts when you sign in again — so anything scheduled before you log in runs before the mount exists.

What if the network drops mid-write?

The client reconnects on its own and restores its mounts at start-up. It cannot promise that a single file whose write was interrupted survives untouched — the same is true of any filesystem over an unstable link, so check that file if the connection died during a write.

Which NASes work?

Anything that speaks WebDAV: Synology and QNAP with WebDAV enabled, Nextcloud, AList / OpenList, self-hosted WebDAV services, and cloud drives exposed through a WebDAV gateway. Each service gets its own letter, so several can be mounted at once.
