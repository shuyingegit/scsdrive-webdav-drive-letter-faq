Mount WebDAV / NAS as a Windows drive letter without copying files

Short answer: map the remote share to a local drive letter so apps open paths like Z:\... — no bulk copy to the PC.

ScsDrive does this on Windows for WebDAV / NAS / cloud folders.

  • Product: https://drive.scsoi.com/
  • Download / trial: https://drive.scsoi.com/#download
  • Pricing: https://drive.scsoi.com/#pricing

It is not a same-disk free-space expand tool (that is ScsExpand) and not a local-folder subst letter (that is ScsSubst).

Disclosure: I work on ScsDrive / SCSOI.
